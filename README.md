### Who am I?

I'm a CS undergrad who gets genuinely excited about building things — not just writing code, but shipping products that people actually use.

I've reverse-engineered my university's entire portal to build a better version of it. I've trained object detection models that run faster than the off-the-shelf defaults. I've shipped full-stack platforms to production.

I like the messy, hard problems — the ones where the documentation doesn't exist yet and you have to figure it out yourself.

Right now I'm deep into **Ai**, **LLM-powered apps**, and **cloud infra**. When I'm not building, I'm grinding DSA.
